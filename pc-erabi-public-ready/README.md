## 公開前に必ず行うこと

### 1. URLと連絡先を設定
Pythonが使える環境でフォルダ内から次を実行します。

```bash
python configure_site.py
```

公開URLと、Web上に掲載してよいお問い合わせメールアドレスを入力してください。
これにより `https://fuma7587-del.github.io/pc-erabi` と `rein7587@gmail.com` が一括置換されます。

### 2. ローカル確認
`index.html` を開き、以下を確認します。
- 診断が最後まで動く
- A8.net広告が表示される
- 固定ページと記事へのリンクが開く
- スマホ幅でレイアウトが崩れない

広告ブロッカーを使用しているとA8.net画像が表示されない場合があります。

### 3. GitHub Pages公開
1. GitHubで公開用リポジトリを作成
2. このフォルダの中身をすべてアップロード
3. Settings → Pages
4. Deploy from a branch を選択
5. `main` / `/root` を指定
6. 公開URLが決まった後、未設定なら `configure_site.py` を実行して再アップロード

### 4. Search Console
- 所有権を確認
- `sitemap.xml` を送信
- インデックス登録状況を確認

### 5. AdSense
審査申請前に以下を確認してください。
- 独自ドメインまたは正常に閲覧できる公開URL
- すべてのページが表示可能
- 内容の薄い未完成ページやダミーリンクがない
- プライバシーポリシーと運営者情報が閲覧可能
- サイトのナビゲーションが分かりやすい

審査通過後：
1. AdSense管理画面で発行されたサイトコードを各HTMLの `</head>` 手前へ設置
2. `ads.txt` を管理画面で指定された正式な1行へ置換
3. 必要に応じてGoogleの「プライバシーとメッセージ」から同意管理を設定

## 重要
- AdSenseコードとads.txtの正式な値はアカウントごとに異なるため、事前に埋め込めません。
- 商品価格、在庫、広告内容はリンク先で変化します。
- 法的文書は一般的なひな形です。事業形態や収集データに応じて必要なら専門家へ確認してください。
- A8.netの広告リンクはユーザー提供コードを使用しています。
